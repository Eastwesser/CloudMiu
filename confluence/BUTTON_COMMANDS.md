# Button → command wiring

Reply keyboard labels stay human (`Weather`, `Alice`, …).  
Pressing a button runs the **same handler** as the slash command (no more “click /foo” tease).

| Button label | Slash command(s) |
|--------------|------------------|
| Weather | `/weather_start`, `/weather` (no city → same entry; `/weather City` still works) |
| Alice / YandexGPT | `/ask_miumiu_gpt` |
| Drawer / Kandinsky | `/start_drawer`, `/start_kandinsky` |
| Currency | `/convert_money` |
| Calculator | `/calculator` |
| Converter | `/converter` |
| Magnetic Storm | `/magnetic_storm` |
| Python Presentation | `/presentation` |
| Memes | `/memes` |
| Stickers | `/sticker_kb` |
| Games | opens games keyboard |
| Emoji | opens emoji keyboard |
| Rock Paper Scissors | `/rps` |
| Blackjack | `/start_blackjack` |
| BlockMe! | `/start_block_me` |
| Battleship | `/start_naval` |
| 5 Cats | `/start_five_cats` |
| Dice / Darts / Casino / Football / Basketball / Bowling | `/dice` … `/bowling` |

Video→MP3 removed from help keyboard (feature still commented out).
